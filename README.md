# Check-up – ψηφιακή ανάλυση site

Βάζεις μια διεύθυνση (ή επικολλάς τον κώδικα μιας σελίδας) και παίρνεις αναφορά με:
θετικά, αρνητικά, βαθμό ανά κατηγορία, τις 5 πρώτες κινήσεις, έτοιμο κώδικα διόρθωσης
και σύγκριση δύο site δίπλα-δίπλα. Προαιρετικά προσθέτει και έλεγχο του προφίλ Google Business.

## Τι περιέχει
| Αρχείο | Ρόλος |
|---|---|
| `benchmarks.js` | Η λίστα ανταγωνιστών ανά κατηγορία (την επεκτείνεις εσύ). |
| `analyzer.js` | Η μηχανή ανάλυσης (35 έλεγχοι, μαζί με έλεγχο ποιότητας κειμένου με κανόνες). Τρέχει και στον browser και στον server. |
| `index.html` | Η εφαρμογή (διεπαφή): ο χρήστης γράφει μόνο τη διεύθυνση του site. |
| `src/analyze.js` | Ο κώδικας του server (κατεβάζει το site και τρέχει την ανάλυση). |
| `netlify/functions/analyze.js` | Ο ίδιος server, έτοιμος σε ένα αρχείο, χωρίς εξαρτήσεις. Αυτό ανεβαίνει. |
| `build.js` | Βγάζει το `dist/` (ενσωματώνει τη μηχανή στη σελίδα). |
| `test/` | Τεστ μηχανής, server και διεπαφής. |

## Κείμενα με απόδειξη (χωρίς AI)
Κάθε εύρημα φέρνει παράθεμα και σελίδα (π.χ. «Στη σελίδα /news υπάρχει ειδοποίηση: “…until further notice”»), ημερομηνία της
τελευταίας ανάρτησης στα News/Blog, και «Τι κινδυνεύεις» με προσεκτική διατύπωση («ενδεχομένως»). Η ενότητα «Η εικόνα με λίγα λόγια»
είναι επεξεργάσιμη πρόζα, με πεδία «Σχόλιο συμβούλου» και «Ετοιμάστηκε από» που μπαίνουν στην εκτύπωση/PDF και στο αντιγραμμένο κείμενο.
Τα κείμενα και οι εξηγήσεις βρίσκονται στο `analyzer.js` (`CONSEQ`, `pageReview`, `buildStory`) και αλλάζουν εύκολα.

## Πώς δουλεύει για τον χρήστη
Ο χρήστης ανοίγει τη σελίδα, γράφει `onoma.gr` και πατά το κουμπί. Σε λίγα δευτερόλεπτα βλέπει την αναφορά.
Ο server διαβάζει το site (αρχική και έως 4 εσωτερικές σελίδες, robots.txt, sitemap) και η μηχανή βγάζει τα ευρήματα.

## Ανέβασμα στο Netlify (δύο τρόποι)
**Α. Χωρίς Git (πιο γρήγορα):** βγάλε το zip σε φάκελο, συνδέσου στο Netlify και σύρε τον φάκελο στο
app.netlify.com/drop. Το Netlify τρέχει το `node build.js` και δημοσιεύει σελίδα και server.
**Β. Με GitHub:** ανέβασε τον φάκελο σε repository, Netlify → Add new site → Import from Git. Οι ρυθμίσεις
διαβάζονται από το `netlify.toml` (build: `node build.js`, publish: `dist`, functions: `netlify/functions`).

Όταν ανοίξεις το site, πρέπει να βλέπεις πεδίο «Διεύθυνση site». Αν βλέπεις μήνυμα «Προεπισκόπηση», ο server
δεν δημοσιεύτηκε (έλεγξε ότι υπάρχει ο φάκελος `netlify/functions` στα deploy logs).

## Ανταγωνιστές (αυτόματη εύρεση και σύγκριση 3 στηλών)
Μετά την ανάλυση, η αναφορά βρίσκει μόνη της ανταγωνιστές και δείχνει «Εσύ και οι ανταγωνιστές» (3 στήλες).
1. Από το site φτιάχνεται φράση αναζήτησης (π.χ. «σύμβουλοι εστίασης τουρισμού Αθήνα»). Ο χρήστης μπορεί να τη διορθώσει.
2. Ο server ψάχνει με τη σειρά, ώσπου να βρει τουλάχιστον 2 sites:
   * **Tavily** (αναζήτηση στο διαδίκτυο, δωρεάν πλάνο· θέλει κλειδί `TAVILY_API_KEY`),
   * **Google Places** (αν υπάρχει `GOOGLE_PLACES_API_KEY`· χρεώνεται πέρα από το δωρεάν όριο),
   * **OpenStreetMap** (δωρεάν, χωρίς κλειδί· μόνο για τοπικές επιχειρήσεις με γνωστή πόλη και δραστηριότητα).
3. Αν δεν βρεθεί τίποτα, χρησιμοποιείται η λίστα `benchmarks.js` (αν ταιριάζει κατηγορία), αλλιώς ο χρήστης γράφει τα sites.
4. Φιλτράρονται social, καταλόγοι, marketplaces, ειδησεογραφικά και σελίδες-λίστες, και αναλύονται τα 2 πρώτα που διαβάζονται.

**Κλειδί Tavily:** στο tavily.com δημιουργείς λογαριασμό και παίρνεις API key. Στο Netlify → Environment variables βάλε `TAVILY_API_KEY`.
Έλεγξε τους όρους και τα όρια του δωρεάν πλάνου στην ιστοσελίδα τους.
**OpenStreetMap:** βάλε `CONTACT_EMAIL` (το email σου) στο Netlify, γιατί οι όροι του Nominatim ζητούν αναγνωρίσιμο User-Agent.
Τα δεδομένα είναι © OpenStreetMap contributors· η εφαρμογή το γράφει όταν τα χρησιμοποιεί.
Τα δημόσια Nominatim/Overpass είναι εθελοντικά (Nominatim έως 1 αίτημα/δευτ.· Overpass μέχρι ~10.000 ερωτήματα/ημέρα).

**Όρια:** η αυτόματη εύρεση δεν εγγυάται σχετικούς ανταγωνιστές (το OpenStreetMap δεν έχει «δημοφιλία»). Γι' αυτό υπάρχει η φράση
αναζήτησης, το «Άλλοι ανταγωνιστές» και τα δύο πεδία με δικά σου sites.

**Λίστα εφεδρείας:** στο `benchmarks.js` πρόσθεσε γραμμές `{ cat, city, name, url }` όπου θέλεις σίγουρους ανταγωνιστές.

### Ταχύτητα με Google PageSpeed (δωρεάν, προαιρετικό)
Δείχνει βαθμό απόδοσης, Core Web Vitals και τι θα επιταχύνει τη σελίδα. Η Google το δίνει δωρεάν με όριο 25.000 μετρήσεις τη μέρα.
1. Google Cloud Console → νέο project → APIs & Services → Library → ενεργοποίησε το **PageSpeed Insights API**.
2. Credentials → Create credentials → **API key**.
3. Στο κλειδί βάλε περιορισμούς: **Application restrictions → Websites** με τη διεύθυνση του site σου
   (π.χ. `https://onoma.netlify.app/*`) και **API restrictions → PageSpeed Insights API**.
   Το κλειδί φαίνεται στον browser, γι' αυτό οι περιορισμοί είναι απαραίτητοι.
4. Netlify → Site configuration → Environment variables → `PAGESPEED_API_KEY` = το κλειδί. Κάνε νέο deploy.
Η μέτρηση γίνεται από τον browser του χρήστη προς τη Google (όχι από το Netlify), γιατί κρατά 10–30 δευτερόλεπτα και οι
δωρεάν functions έχουν όριο περίπου 10 δευτερολέπτων. Χωρίς κλειδί, η ενότητα ταχύτητας απλώς δεν εμφανίζεται.

### Αναζήτηση με όνομα επιχείρησης (προαιρετικό)
Θέλει κλειδί Google Places API (η Google χρεώνει ανά αίτημα).
Netlify → Site settings → Environment variables → `GOOGLE_PLACES_API_KEY`.
Τότε το πεδίο δέχεται και όνομα, δείχνει υποψήφιες επιχειρήσεις και προσθέτει έλεγχο προφίλ Google
(βαθμολογία, κριτικές, ωράριο, τηλέφωνο, φωτογραφίες έως 10). Δεν φαίνονται προβολές ή κλήσεις·
για αυτά χρειάζεται το Business Profile API με έγκριση της Google και σύνδεση του ιδιοκτήτη.

## Ασφάλεια και όρια
* Ο server μπλοκάρει τοπικές/ιδιωτικές διευθύνσεις (SSRF), όριο 2 MB ανά σελίδα, χρονικό όριο 12 s,
  έως 5 ανακατευθύνσεις και 12 αιτήματα το λεπτό ανά IP (σε μνήμη· για μεγάλη χρήση βάλε σωστό rate limit).
* Ορισμένα sites (π.χ. πίσω από Cloudflare) μπλοκάρουν αυτόματες αναγνώσεις. Τότε εμφανίζεται σχετικό μήνυμα και ο χρήστης μπορεί να χρησιμοποιήσει την επικόλληση κώδικα (προχωρημένα).
* Δεν μετριέται ταχύτητα ούτε θέση στη Google. Οι βαθμοί είναι ενδεικτικοί.
* Μην αναλύεις sites χωρίς λόγο σε μεγάλο όγκο· τηρείς τους όρους των sites που ελέγχεις.

## Πώς προσθέτεις έλεγχο
Στο `analyzer.js`, στον πίνακα `CHECKS`, πρόσθεσε αντικείμενο με `id`, `cat`, `w` (βάρος), `name`, `why`, `fix`
και συνάρτηση `run(S)` που επιστρέφει `{ s: 0..1, ev: ['…'] }` ή `null` αν δεν εφαρμόζεται.
